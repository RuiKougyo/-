# LINEスケジュール管理bot（Google Apps Script版）

LINEで予定を送るだけで登録でき、時間が近づくとLINEでお知らせしてくれるbotです。

- **無料・サーバー不要**：Google Apps Script（GAS）で動き、予定はGoogleスプレッドシートに保存されます
- 1対1のトークでも、**LINEグループ**でも使えます（グループの予定はメンバー全員で共有）
- 予定の**◯分前のリマインド**と、**毎朝の「今日の予定」**を自動で送ります

> 📌 全部で30分ほどで設定できます。画面の文言は各サービスの変更で少し違うことがあります。

## 使い方（LINEで送る言葉）

### 予定を登録する

| 送る文 | 登録される内容 |
|---|---|
| `10/20 14:00 歯医者` | 10月20日 14:00 歯医者 |
| `10月20日 14時半 歯医者` | 10月20日 14:30 歯医者 |
| `明日 9時 会議` / `あさって 午後3時 打ち合わせ` | 明日・明後日 |
| `金曜 19:00~21:00 飲み会` | 次の金曜日 19:00（内容は「~21:00 飲み会」） |
| `来週月曜 10:00 面談` | 来週の月曜日 |
| `15:00 電話` | 日付なし → 今日（過ぎていれば明日） |
| `12/24 クリスマス` | 時刻なし → **終日**の予定 |
| `2027/1/5 9:00 初詣` | 年を指定（省略すると、過ぎた日付は来年とみなします） |

数字や記号は全角でも大丈夫です。

### 予定を見る・消す

| 送る文 | 動作 |
|---|---|
| `一覧`（または `予定`） | これからの予定を番号つきで表示 |
| `今日` / `明日` / `今週` | その期間の予定を表示 |
| `削除 3` | 番号3の予定を削除（`削除 3 5` で複数まとめて） |
| `ヘルプ` | 使い方を表示 |

返信の例：

```
📅 これからの予定（2件）

■ 10/20(火)
[1] 14:00 歯医者

■ 10/24(土)
[2] 終日 キャンプ
```

### グループで使うとき

普段の会話に反応しないよう、グループでは **頭に「予定」を付けて** 送ります。

- 登録：`予定 明日 9時 集合`
- 確認：`一覧`、`予定 今日`、`明日の予定`（「明日」だけでは反応しません）
- 削除：`削除 3`

グループの予定はそのグループのメンバー全員で共有され、一覧には登録した人の名前が表示されます。
1対1トークの予定とグループの予定は別々に管理されます（ほかのトークの予定は見えず、消せません）。

### 自動のお知らせ

- **リマインド**：時刻つきの予定の **30分前**（変更可）にお知らせ
- **朝のお知らせ**：毎朝 **7時台**（変更可）に、その日の予定があるトークへまとめて送信

## 手順1. LINE公式アカウントとチャネルを作る

1. [LINE Developers](https://developers.line.biz/) を開き、LINEアカウントでログインします
2. 「プロバイダー」を作成します（名前は自由。例：`自分用bot`）
3. 「新規チャネル作成」→ **Messaging API** を選びます
   - 画面の案内に従って LINE公式アカウントを作成すると、Messaging APIのチャネルが作られます
4. チャネルの **「Messaging API設定」** タブを開き、次の操作をします
   - 一番下の **「チャネルアクセストークン（長期）」** の「発行」を押し、表示された長い文字列をメモします
     **⚠️ このトークンは他人に教えないでください**
   - **「応答メッセージ」** の「編集」から LINE Official Account Manager を開き、
     **応答メッセージ：オフ / Webhook：オン** にします
   - グループで使う場合は **「グループトーク・複数人トークへの参加を許可する」** をオンにします
5. 同じ画面の **QRコード** をスマホのLINEで読み取り、botを友だち追加しておきます

---

## 手順2. スプレッドシートにプログラムを貼り付ける

1. [Googleスプレッドシート](https://sheets.google.com/) で **空のスプレッドシート** を新規作成します（名前は例：`LINE予定bot`）
2. メニューの **「拡張機能」→「Apps Script」** を開きます
3. 左の「ファイル」に最初からある `コード.gs` を開き、中身をすべて消して、
   このフォルダの [`src/Main.js`](src/Main.js) の中身をすべて貼り付けます
4. 「ファイル」の横の **＋ → スクリプト** で新しいファイルを作り、名前を `Parser` にして、
   [`src/Parser.js`](src/Parser.js) の中身をすべて貼り付けます
5. 左の歯車 **「プロジェクトの設定」** を開き、**タイムゾーン** を `(GMT+09:00) 日本標準時` にします
6. 💾 ボタンで保存します

> 💡 clasp（GAS用のコマンドラインツール）を使える方は、`src` フォルダをそのまま `clasp push` しても構いません。

---

## 手順3. トークンを設定して setup を実行する

1. Apps Script の **「プロジェクトの設定」** を開き、一番下の **「スクリプト プロパティを追加」** を押します
2. 次のように入力して保存します

   | プロパティ | 値 |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | 手順1でメモしたチャネルアクセストークン |

3. 左の **「エディタ」** に戻り、上の関数の選択欄で **`setup`** を選んで **「実行」** を押します
4. 初回は「承認が必要です」と出るので、**権限を確認 → 自分のGoogleアカウント → 詳細 → （安全ではないページ）に移動 → 許可** と進みます
   - 自分で作ったスクリプトなので、この警告が出るのは正常です
5. 実行ログに「セットアップが完了しました」と出れば成功です
   - スプレッドシートに `予定` シートができ、リマインド（5分ごと）と朝のお知らせのトリガーが登録されます

---

## 手順4. ウェブアプリとして公開し、LINEにURLを登録する

1. Apps Script 右上の **「デプロイ」→「新しいデプロイ」** を押します
2. 歯車から種類 **「ウェブアプリ」** を選び、次のように設定して「デプロイ」を押します
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピーします
4. LINE Developers の「Messaging API設定」→ **Webhook URL** に貼り付けて「更新」し、**「Webhookの利用」をオン** にします
5. LINEでbotに `ヘルプ` と送り、使い方が返ってくれば完成です 🎉

> ⚠️ **プログラムを書き換えたとき**は、「デプロイ」→「デプロイを管理」→ 鉛筆マーク →
> バージョン「**新バージョン**」→「デプロイ」で更新してください（URLは変わりません）。
> 「新しいデプロイ」を作るとURLが変わるので、LINE側の登録もやり直しになります。

## 設定を変えたいとき

「プロジェクトの設定」→ スクリプト プロパティで変更できます。**変更後はもう一度 `setup` を実行**してください。

| プロパティ | 意味 | 既定値 |
|---|---|---|
| `REMIND_MINUTES` | 何分前にリマインドするか。`0` でリマインドしない | `30` |
| `MORNING_HOUR` | 朝のお知らせの時刻（0〜23）。`-1` で送らない | `7` |
| `GROUP_REQUIRE_PREFIX` | `false` にすると、グループでも「予定」なしで登録できる | `true` |

- リマインドは5分ごとに確認するので、通知時刻は最大5分ほど前後します
- 朝のお知らせはGoogleの仕様で「7時台のどこか」に届きます（7:00ちょうどとは限りません）
- 登録した予定はスプレッドシートの `予定` シートで直接見られます。30日以上前の予定は自動で片付けます

## ご注意（送信数の上限・セキュリティ）

### 月の送信数の上限

LINE公式アカウントの無料プラン（コミュニケーションプラン）では、**botから自分で送るメッセージは月200通まで**です。

- **登録・一覧などへの返信は無料**で、上限にカウントされません
- **リマインドと朝のお知らせはカウントされます**
- グループへの送信は **「メンバーの人数」通分** としてカウントされます（5人のグループへ1回送ると5通）

予定が多い場合やグループで使う場合は、`MORNING_HOUR` を `-1` にする・`REMIND_MINUTES` を `0` にするなどで調整してください。
上限を超えると、その月はリマインドなどが届かなくなります（返信は引き続き使えます）。
最新の料金プランはLINEヤフーの公式サイトでご確認ください。

### セキュリティについて

- チャネルアクセストークンとウェブアプリのURLは他人に教えないでください
- GASの仕様上、LINEからのリクエストの署名（本物のLINEからの通信かどうか）を確認できません。
  URLが漏れると、第三者が偽の予定を登録できる可能性があります。個人や家族・友人での利用を想定しています
- 予定の内容はご自身のGoogleスプレッドシートに保存されます

## よくあるトラブル

| 症状 | 確認すること |
|---|---|
| 何を送っても返事がない | Webhook URL が `/exec` で終わっているか、「Webhookの利用」がオンか、デプロイの「アクセスできるユーザー」が「全員」か |
| LINEの「検証」ボタンでエラーが出る | GASは応答の仕組み上、検証でエラー表示になることがあります。実際にメッセージを送って返事があれば問題ありません |
| 「応答メッセージ」の定型文が返ってくる | LINE Official Account Manager で応答メッセージをオフにする |
| プログラムを直したのに反映されない | 「デプロイを管理」から **新バージョン** でデプロイし直す |
| リマインドが来ない | `setup` を実行したか（Apps Script の「トリガー」に `checkReminders` があるか）、月の送信数の上限を超えていないか |
| グループに招待できない | 「グループトーク・複数人トークへの参加を許可する」がオンか |
| エラーの内容を見たい | Apps Script の左メニュー **「実行数」** でログを確認できます |

## 開発者向け情報

```
line_schedule_bot/
├── src/
│   ├── Main.js          … LINEの受信・コマンド処理・リマインド・保存（スプレッドシート）
│   ├── Parser.js        … 「10/20 14:00 歯医者」などの読み取りと日付表示（純粋な関数のみ）
│   └── appsscript.json  … GASのマニフェスト（タイムゾーン Asia/Tokyo・V8）
├── tests/bot.test.js    … Node.jsでのテスト（Googleのサービスは偽物に差し替え）
└── package.json
```

テストの実行（Node.js 18以上）：

```bash
cd line_schedule_bot
npm test
```

主な関数：

| 関数 | 役割 |
|---|---|
| `doPost` | LINEのWebhookの入口。再送されたイベントは二重登録しないよう無視 |
| `handleText_` | 受け取った文から返信文を作る（コマンド判定・登録） |
| `checkReminders` | 5分ごとのトリガー。開始まで `REMIND_MINUTES` 分以内の予定をプッシュ通知 |
| `sendMorningDigest` | 毎朝のトリガー。今日の予定をトークごとにまとめて送信し、古い予定を削除 |
| `setup` | シート作成とトリガー登録（何度実行しても重複しません） |
