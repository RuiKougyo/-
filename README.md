# EC新着・値下げ監視ツール（楽天市場対応版）

楽天市場で「条件に合う新しい商品」や「値下がりした商品」を見つけると、
Discord（ディスコード）に自動で通知するツールです。

- 楽天の**公式API**だけを使います（お店のページを読み取る「スクレイピング」は使いません）
- パソコンにPythonなどを入れる必要はありません。**exeファイルと設定ファイルだけ**で動きます
- Yahoo!ショッピングへの対応は、次のバージョンで追加予定です

> 📌 **この手順書の読み方**
> 手順1〜4を順番に進めてください。全部で30分〜1時間ほどかかります。
> 画面の文言やボタンの位置は、各サービスの変更で少し変わっていることがあります。

## 手順1. 楽天のアプリケーションID・アクセスキーを取得する

楽天のAPIを使うための「鍵」を、ご自身の楽天会員アカウントで無料で発行します。
**この鍵は他の人に教えないでください。**

### 1-1. 自分のパソコンのIPアドレスを調べる

楽天のアプリ登録では、「どのインターネット回線から使うか（IPアドレス）」の登録が必要です。

1. ツールを動かすパソコンで、ブラウザ（Edge や Chrome）を開きます
2. 「確認くん」（`https://www.ugtop.com/spill.shtml`）などのIPアドレス確認サイトを開きます
3. 「あなたのIPアドレス(IPv4)」に表示された `123.45.67.89` のような数字をメモします

> 💡 ご家庭のインターネット回線は、ルーターの再起動などでIPアドレスが変わることがあります。
> 変わった場合は、楽天の管理画面で登録し直します（[よくあるトラブル](#よくあるトラブル)を参照）。

### 1-2. 楽天ウェブサービスにログインする

1. ブラウザで **楽天ウェブサービス**（`https://webservice.rakuten.co.jp/`）を開きます
2. 画面右上の **「ログイン」** をクリックします
3. 楽天会員のユーザIDとパスワードでログインします

### 1-3. アプリを登録する

1. ログイン後の画面で **「+アプリID発行」**（または「アプリ一覧」→「新規アプリ作成」）をクリックします
2. 登録画面で、次のように入力します

   | 入力欄 | 入力する内容 |
   |---|---|
   | アプリ名 | 分かりやすい名前（例：`EC監視ツール`） |
   | アプリURL／許可されたWebサイト | 自分のブログやWebサイトのURL（例：`https://myblog.jp`） |
   | アプリケーションタイプ | 選択肢がある場合は、案内に沿って選んでください（例：Webアプリケーション） |
   | 許可IPアドレス | 1-1でメモしたIPアドレス |
   | その他の項目 | 画面の案内に沿って入力してください |

3. 利用規約を読み、同意にチェックを入れて **「規約に同意して新規アプリを作成」**（または「作成」）をクリックします

### 1-4. アプリケーションID・アクセスキーを控える

アプリの作成が終わると、アプリの情報が表示されます。次の2つを、メモ帳などに控えてください。

| 名前 | 見た目の例 |
|---|---|
| **アプリケーションID**（Application ID） | `2fc160ec-xxxx-xxxx-xxxx-xxxxxxxxxxxx`（英数字とハイフン） |
| **アクセスキー**（Access Key） | `pk_xxxxxxxxxxxxxxxx`（`pk_` で始まる） |

あわせて、1-3で入力した **「許可されたWebサイト」のURL** も控えておきます。

> 💡 「アフィリエイトID」も表示されますが、このツールでは使いません。

## 手順2. DiscordのウェブフックURLを作る

「ウェブフック」は、ツールからDiscordのチャンネルにメッセージを送るための専用の宛先です。

1. Discord（アプリまたはブラウザ版）を開きます
2. 通知を受け取りたい**サーバー**を選びます
   - 自分専用のサーバーがない場合は、左端の **「＋」（サーバーを追加）** →「オリジナルの作成」→「自分と友達のため」で作れます
3. 通知を受け取りたい**テキストチャンネル**の名前にマウスを乗せ、表示される **⚙（チャンネルの編集）** をクリックします
4. 左のメニューから **「連携サービス」** をクリックします
5. **「ウェブフックを作成」**（すでにある場合は「ウェブフックを確認」→「新しいウェブフック」）をクリックします
6. 作られたウェブフック（「Spidey Bot」などの名前）をクリックして開きます
   - 名前は「EC監視」などに変えても大丈夫です
7. **「ウェブフックURLをコピー」** をクリックします
8. メモ帳などに貼り付けて控えます（`https://discord.com/api/webhooks/` で始まる長いURLです）
9. 画面下に「変更を保存」が出ていればクリックします

> ⚠️ ウェブフックURLを知っている人は、誰でもそのチャンネルに書き込めます。他の人に教えないでください。

## 手順3. 設定ファイルを書く

### 3-1. 設定ファイルを用意する

1. `config.sample.yaml` をコピーして、同じフォルダに貼り付けます
2. コピーしたファイルの名前を **`config.yaml`** に変えます

> 💡 `ECMonitor.exe` を一度ダブルクリックすると、`config.yaml` を自動で作ることもできます。
>
> 💡 ファイル名の「.yaml」が見えない場合は、エクスプローラーの上部メニュー
> 「表示」→「表示」→「ファイル名拡張子」にチェックを入れてください。

### 3-2. メモ帳で開いて書き換える

`config.yaml` を右クリック →「プログラムから開く」→「メモ帳」で開きます。

**① Discordの設定** — 手順2のURLを貼り付けます

```yaml
discord:
  webhook_url: "https://discord.com/api/webhooks/1234567890/abcdefg..."
```

**② 楽天の設定** — 手順1で控えた3つを入力します

```yaml
rakuten:
  application_id: "2fc160ec-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  access_key: "pk_xxxxxxxxxxxxxxxx"
  allowed_website: "https://myblog.jp"
```

**③ 監視条件** — 探したい商品の条件を書きます

```yaml
watches:
  - name: "Switch本体"               # 監視条件の名前（通知に表示されます）
    site: rakuten                     # 対象サイト
    keyword: "Nintendo Switch 本体"   # 検索キーワード
    exclude_keywords:                 # 商品名にこの言葉が入っていたら通知しない
      - "中古"
      - "ジャンク"
    min_price: 20000                  # 価格の下限（円）
    max_price: 40000                  # 価格の上限（円）
    interval_minutes: 10              # 何分ごとにチェックするか
    max_pages: 1                      # 何ページ分チェックするか（1ページ＝30件）
    sort: newest                      # 並び順
    in_stock_only: true               # 在庫ありの商品だけにするか
```

#### 監視条件の項目の説明

| 項目 | 説明 | 省略したとき |
|---|---|---|
| `name` | 条件の名前。**条件ごとに別の名前**にしてください | 省略できません |
| `site` | 対象サイト。今は `rakuten` のみ | `rakuten` |
| `keyword` | 検索キーワード。空白で区切ると「すべての言葉を含む」検索になります | 省略できません |
| `exclude_keywords` | 除外したい言葉。1行に1つずつ「`- "言葉"`」の形で書きます | 除外なし |
| `min_price` / `max_price` | 価格の下限・上限（円）。数字だけを書きます（`20,000` や `円` は不要） | 制限なし |
| `interval_minutes` | 何分ごとにチェックするか。**最小5分**です（下の説明を参照） | `10` |
| `max_pages` | 何ページ分チェックするか（1〜10）。増やすと見落としは減りますが、APIを使う回数が増えます | `1` |
| `sort` | `newest`（更新が新しい順）／`price_asc`（安い順）／`standard`（楽天の標準） | `newest` |
| `in_stock_only` | `true` にすると在庫ありの商品だけ | `true` |

#### 監視条件を増やすには

`- name:` から始まるひとかたまりを**まるごとコピー**して、下に貼り付け、内容を書き換えます。
**行の先頭の空白（字下げ）をそろえる**のがポイントです。

#### 全体の設定（settings）

| 項目 | 説明 | おすすめ |
|---|---|---|
| `first_run_notify` | 初めてチェックしたときに見つかった商品も通知するか。`true` にすると最初に大量の通知が届きます | `false` |
| `min_drop_yen` | 何円以上値下がりしたら通知するか | `1` |
| `min_drop_percent` | 何％以上値下がりしたら通知するか（`0` なら割合は見ない） | `0` |
| `log_level` | ログの細かさ | `INFO` |

### 3-3. 保存する

メモ帳の「ファイル」→「上書き保存」で保存します。
（「名前を付けて保存」する場合は、文字コードを **UTF-8** にしてください）

> ⚠️ **書き方の注意**
> - 空白は必ず**半角スペース**を使ってください（全角スペースはエラーになります）
> - `:` の後ろには半角スペースを1つ入れてください
> - 文字の前後の `"`（ダブルクォーテーション）は消さないでください

## 手順4. 起動する

### 4-1. まず設定を確認する（テストモード）

1. フォルダの何もないところで **Shiftキーを押しながら右クリック** →「ターミナルで開く」（または「PowerShell ウィンドウをここで開く」）をクリックします
2. 開いた画面に次のように入力して、Enterキーを押します

   ```
   .\ECMonitor.exe --test
   ```

3. 次のように表示されれば成功です
   - Discordに **「✅ テスト通知」** が届く
   - 画面に「楽天市場のAPIに接続できました」と表示される
   - 最後に「設定の確認が完了しました。問題はありません。」と表示される

エラーが表示された場合は、メッセージを読んで `config.yaml` を直してください。
（[よくあるトラブル](#よくあるトラブル)も参考にしてください）

> 💡 初めて起動するときに **「WindowsによってPCが保護されました」** という青い画面が出ることがあります。
> その場合は **「詳細情報」** →「**実行**」をクリックしてください。

### 4-2. 監視を開始する

**`ECMonitor.exe` をダブルクリック**するだけです。黒い画面が開き、監視が始まります。

```
2026-10-04 10:00:00 [情報] 監視を開始します（監視条件 2件）。
2026-10-04 10:00:02 [情報] 「Switch本体」楽天市場：取得 30件／条件に合う商品 12件／通知 新着0件・値下げ0件（初回チェックのため、見つかった商品は記録のみで通知していません）
```

- **最初のチェックでは通知しません**（今ある商品を記録するだけです）。2回目以降に、新しく出てきた商品や値下がりした商品が通知されます
- **黒い画面を閉じると監視が止まります**。監視中は開いたままにしてください（最小化はOK）
- パソコンがスリープや電源オフになると監視も止まります。再開したら、もう一度ダブルクリックしてください

### 4-3. 監視を止める

黒い画面で **Ctrl + C** を押すか、画面の「×」で閉じます。
次に起動したときは、前回までの記録を引き継ぐので、同じ商品を重複して通知することはありません。

### （おまけ）パソコンを起動したら自動で監視を始める

1. `ECMonitor.exe` を右クリック →「その他のオプションを確認」→「ショートカットの作成」
2. キーボードの **Windowsキー + R** を押し、`shell:startup` と入力してEnter
3. 開いたフォルダに、1で作ったショートカットを移動します

## 通知の見方

Discordには、次のようなカードが届きます。

| 種類 | 色 | 内容 |
|---|---|---|
| 🆕 新着 | 緑 | これまでに見つけていなかった商品 |
| 💸 値下げ | 赤 | 前回通知したときより安くなった商品。**値下げ前の価格**（取り消し線）と、いくら安くなったかを表示 |

各カードには、商品名（クリックすると商品ページが開きます）、価格、ショップ名、商品画像が表示されます。

### 「新着」「値下げ」の判定について

- **新着**：楽天のAPIには「新しく出品された」という情報がないため、
  「**このツールがその監視条件で初めて見つけた商品**」を新着としています
- **値下げ前の価格**：「**このツールが前回通知したときの価格**」です。
  お店が表示している「通常価格」「メーカー希望小売価格」とは異なります
- 価格が「1,000円 → 900円 → 1,000円 → 900円」のように上下しても、同じ値下げを何度も通知しません
- **監視条件（キーワードや価格など）を変更すると、その条件は「初回」扱い**に戻り、次のチェックでは記録のみ行います（大量通知を防ぐため）

## よくあるトラブル

| 画面のメッセージ | 原因と対処 |
|---|---|
| 設定ファイルが見つかりません／ひな形を作成しました | `config.yaml` がexeと同じフォルダにありません。手順3を行ってください |
| 設定ファイルの書き方に誤りがあります（○行目付近） | その行の近くで、字下げのずれ・全角スペース・`:` の後の空白忘れがないか確認してください |
| ○○を入力してください | `config.yaml` の該当箇所が「ここに～」のままです |
| **このパソコンのIPアドレスが「許可IPアドレス」に登録されていません** | ご家庭の回線のIPアドレスが変わった可能性があります。手順1-1でIPアドレスを調べ直し、楽天ウェブサービスの「アプリ一覧」→ 該当アプリの編集画面で、許可IPアドレスを更新してください |
| **「許可されたWebサイト」と一致しません** | `config.yaml` の `allowed_website` と、楽天のアプリ登録画面の「許可されたWebサイト」を、`https://` から完全に同じにしてください |
| アプリケーションIDまたはアクセスキーが受け付けられませんでした | `application_id` と `access_key` を、コピーし直して貼り付けてください。前後に余計な空白が入っていないかも確認してください |
| APIリクエスト回数の上限に達しました（HTTP 429） | 楽天側の制限です。ツールが自動で待ってから再開するので、そのままで大丈夫です。何度も出る場合は、監視条件を減らすか `max_pages` を小さくしてください |
| 通信に失敗しました（インターネット接続を確認してください） | インターネットにつながっているか確認してください。ツールは自動で再試行し、失敗が続くと 1分→2分→4分…（最大60分）と間隔を空けて待ってから再開します |
| DiscordのウェブフックURLが無効です | Discordでウェブフックが削除された可能性があります。手順2でもう一度作り、`webhook_url` を更新してください |
| 通知が来ない | ①初回チェックでは通知しません ②条件に合う商品の変化がないと通知しません ③黒い画面に表示されている「条件に合う商品」の件数を確認し、0件なら条件を見直してください |
| 監視間隔を○分→○分に調整しました | APIの利用上限を守るための自動調整です。問題ありません |

### 動作の記録（ログ）

exeと同じフォルダの **`logs`** フォルダに、`monitor.log` として日本語で記録されています。
困ったときは、このファイルを見ると原因が分かることがあります。
（ログには、APIキーやウェブフックURLは記録されません）

### 記録をリセットしたいとき

exeと同じフォルダの **`data`** フォルダを削除すると、これまでの記録がすべて消え、すべての監視条件が「初回」に戻ります。

## ご利用上の注意（規約について）

このツールは、各サービスの規約を守って動くように作っています。ご利用にあたって、次の点をお守りください。

- **APIキーは、ご自身で取得したものをお使いください。** 他の人と共有したり、他の人に教えたりしないでください
- 楽天ウェブサービスの[利用規約](https://webservice.rakuten.co.jp/guide/rule)に同意したうえでご利用ください
- **リクエスト回数の上限**：楽天のAPIは「1つのアプリケーションIDにつき1秒に1回まで」です。このツールは、必ず**2秒以上の間隔**を空けてアクセスします。また、監視間隔は**最小5分**で、監視条件が多いときは自動で長くします
- **クレジット表示**：楽天の規約では、APIを使っていることの表示（クレジット表示）が必須です。そのため、Discordの通知の下部に「Supported by Rakuten Developers」と表示しています
- **取得した情報の使い方**：楽天のAPIで得た情報は、「商品の紹介と、商品ページへのリンク」の目的で使うことが認められています。通知の内容を加工して転載するなど、それ以外の目的には使わないでください
- このツールが保存するのは、重複通知を防ぐための最小限の情報（商品コード・商品名・価格・日時）だけです

## 開発者向け情報

### フォルダ構成

```
run.py                   exe化の入口
ec_monitor/
├─ main.py               起動処理（--test / --once）
├─ config_loader.py      設定ファイルの読み込みとチェック、監視間隔の最小値の計算
├─ rate_limiter.py       サイトごとのリクエスト間隔の制御
├─ http_client.py        通信と自動再試行（429・5xx・通信エラー）
├─ sites/
│   ├─ base.py           サイト共通の形
│   └─ rakuten.py        楽天市場 商品検索API（2026-07-01版）
├─ filters.py            除外キーワード・価格での絞り込み
├─ detector.py           新着・値下げの判定
├─ storage.py            SQLiteでの記録（data/state.db）
├─ notifier.py           Discordウェブフック通知
├─ monitor.py            監視ループ、エラー時の待機（バックオフ）
├─ log_setup.py          日本語ログ（logs/monitor.log、自動で整理）
└─ paths.py              exe化したときのファイルの場所
tests/                   自動テスト（実際のAPIにはアクセスしません）
config.sample.yaml       設定ファイルのひな形（exeにも同梱）
ec_monitor.spec          PyInstallerの設定
build.bat                exeを作るバッチファイル
```

```
pip install -r requirements.txt
python run.py --test
python run.py
```

### exeを作る（Windows）

Python 3.10以上が入ったWindowsで `build.bat` をダブルクリックします。
テストが通ると `release` フォルダに `ECMonitor.exe`・`config.sample.yaml`・`README.md` がそろうので、その中身を配布します。

### API上限を守る仕組み

| 仕組み | 内容 |
|---|---|
| リクエスト間隔 | 楽天へのリクエストは必ず `rate_limiter.py` を通り、前回から2秒以上空ける（規約は1秒に1回） |
| 監視間隔の最小値 | 「全監視条件のページ数 × 2秒 × 2倍」と5分の大きい方。設定値がこれより短ければ自動で延長 |
| 再試行 | 429・5xx・通信エラーはその場で10秒・30秒待って最大2回再試行（`Retry-After` があれば従う） |
| バックオフ | 再試行しても失敗したら、そのサイトを1分→2分→4分…最大60分休止 |
| 認証エラー | 30分休止し、Discordに1回だけお知らせを送る |
